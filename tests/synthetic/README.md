# Synthetic Test Cases

本目录用于说明**人工合成（Synthetic）的 LS-DYNA 风格测试数据与用例**约定。当前 synthetic 页面主要由测试代码动态生成，未来如增加 fixture 文件也放置于此。

### 规范要求
- **严禁复制、截取或分发 LS-DYNA 官方手册的原文或 PDF 片段**；
- 所有测试用例（如伪造的关键字、卡片定义、跨页排版样本）均应由开发者自行编写或程序生成，仅用于验证解析、重构算法与 Markdown 渲染逻辑；
- 合成用例可模拟不同 release 的版式差异（如重复印刷页码、无页脚区域、TOC 页码错误），但仍不得包含官方手册内容。
